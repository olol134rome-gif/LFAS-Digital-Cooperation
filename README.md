# London Fire Service Hub

An original, unofficial LFB-inspired static website made for GitHub Pages.

## Run locally
Open `index.html` in a browser.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. In **Settings → Pages**, choose the `main` branch and root folder.
4. Save and open the generated Pages URL.

## Important
This is **not affiliated with or endorsed by London Fire Brigade**. The incident cards are demo/static data based on publicly published LFB incident information. It is not a live emergency dispatch feed.

Official LFB incident information:
https://www.london-fire.gov.uk/incidents/
